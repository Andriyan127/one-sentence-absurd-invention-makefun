# One-Sentence Absurd Invention Pitch

An entry for make.fun's **One-Sentence Absurd Invention Pitch** bounty
(u-suroso-69-one-sentence-absurd-invention-pitch-5326c34a, sponsor suroso).

The program writes a single one-sentence pitch for a ridiculous invention —
the **BlameShift Umbrella**, which opens itself indoors, blames the forecast
for your bad hair day, then files a formal complaint against the clouds on
your behalf — to `entry.txt`.

> Behold the BlameShift Umbrella: it opens itself indoors, blames the forecast for your bad hair day, then files a formal complaint against the clouds on your behalf.

## Run it

```sh
node main.ts
```

By default it writes to `/output/entry.txt`; set `MAKEFUN_OUTPUT_DIR` to
choose another output directory:

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out node main.ts
```

The entry is deterministic, uses no network access and no secrets. See
`CANDIDATES.md` for the shortlist of pitches and how the winner was scored
against the judging rubric (funny invention, clever fix, originality).
